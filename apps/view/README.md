# VIEW — BMP/PCX picture viewer

Decodes BMP (8/24/32-bit uncompressed) and PCX (8-bit RLE) files on the
emulated 8086 and dithers them onto the CGA screen. Written in Turbo
Pascal 3 with hand-written 8086 machine code for the inner loops
(generated by `mkviewasm.py`).

## Usage

```
VIEW picture[.bmp|.pcx]       640x200 mono, ordered dither (CGA mode 6)
VIEW picture.bmp 4            320x200 four-colour dither   (CGA mode 4)
VIEW picture.bmp 4 0          same, but CGA palette 0 (green/red/brown)
VIEW *.BMP                    slideshow: any key = next, ESC = quit
```

Any key exits. On the SNES, L/R pan the 512-pixel window across the 640.
Images up to 2048 pixels wide; aspect is preserved (CGA pixels are not
square).

Mode 4 defaults to CGA palette 1 (cyan/magenta/white). A trailing `0`
after the `4` selects CGA palette 0 (green/red/brown) instead: the
per-channel dither thresholds map green→green, red→red and
red+green→brown, and pure blue — which has no home in palette 0 — folds
to its nearest colour, black.

## Files

- `view.pas` — the source. Note the TP3 traps documented inline: typed
  constants are CS-relative while the inline machine code reads tables
  via DS (`ColorMap`/`ColorMap0` are therefore copied into the DS
  variable `CMap` at startup, and the palette choice just picks which
  one gets copied), and TP3 keeps SS≠DS, so all inline-asm state lives
  in globals.
- `mkviewasm.py` — generates the `inline()` machine-code blocks.
- `mkcard.py` — generates `CARD.BMP`, the CC0 test card.
- `view.com` — the committed binary. Rebuild with `make recompile`
  (TP3 driven inside runpc — see `../tpcompile.sh`); a rebuilt .COM can
  differ from the committed one by a few inert load-segment bytes, so
  compare behaviour (rendered output), never bytes.

## Verification

`apps/rebuild_all.sh` recompiles view.com and requires the rebuilt
binary to render `CARD.BMP` bit-identically to the committed one;
`snes/test/suite.sh` has a `view-host` leg that paints the test cards
under runpc and checks the CGA framebuffer dump.
